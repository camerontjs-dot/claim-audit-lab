## Architecture consequence

warranted atoms + qualified modifier/integration state
→ module-specific composition logic
→ relation
→ common CompositionReceipt

This avoids forcing each composition module to invent a separate downstream output schema.

The result also makes modifier state first-class for audit purposes even when it is not atomic semantic state.
