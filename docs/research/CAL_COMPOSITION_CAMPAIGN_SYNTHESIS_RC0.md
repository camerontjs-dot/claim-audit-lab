## Converged architecture

The evidence now supports the following research architecture:

```
warranted semantic atoms
        +
qualified cross-cutting modifier / identity state
        ↓
small module-specific composition functions
        ↓
relation
        ↓
common provenance-bearing CompositionReceipt
        ↓
downstream materialization / decision boundary
```

Atomic semantic families remain narrow.

Composition-specific state is explicit and authority-bound:

- temporal rank/binding for quantitative change;
- frame identity for directional composition;
- event-instance identity for occurrence/order;
- subject role/type for population/deontic applicability;
- temporal applicability scope for state-at-time queries.

These properties are not evidence for adding new atomic semantic families.

## What has been falsified

Across the campaign, the following architectural shortcuts are no longer defensible inside the tested bounds:

- universal permissive semantic parsing;
- relation-only composition output;
- input call order as temporal authority;
- approximate/interval evidence silently upgraded to exact change;
- universal spatial transitivity;
- directional inheritance through containment without an explicit rule;
- event joining by normalized fields alone;
- deontic applicability by string equality alone;
- timeless/latest-state persistence;
- modifier state treated as disposable implementation detail;
- warrant state erased during composition.

## What remains open

The composition layer is not yet production-qualified.

The next load-bearing gates are:

1. **portable canonical serialization** for the common composition receipt;
2. **independent consumer verification**, preferably cross-repository;
3. runtime/registry integration of one smallest composition module;
4. compiler/query production for the corresponding composition request;
5. Contract C representation without semantic/provenance loss;
6. pipeline replay and independent reproduction;
7. Decision Engine conformance only after the upstream boundary is stable.

The common carrier result does not prove that current Contract C can represent this state. Existing Contract C losslessness failures remain separate evidence.

## Prototype convergence

The next frozen prototype should therefore be smaller than “all new semantics in production.”

A defensible prototype target is:

- existing qualified atomic family machinery;
- one composition-module registry/seam;
- one common provenance-bearing `CompositionReceipt`;
- portable canonical vectors;
- one independent consumer;
- no production registration until those portability tests pass.

Quantitative change is a strong first end-to-end composition candidate because its semantic bounds are explicit and it exercises temporal bindings, multiple authority inputs, derived arithmetic, and provenance without requiring natural-language coreference.

No merge, release, production promotion, Contract C change, or Decision Engine change is authorized by this synthesis.
