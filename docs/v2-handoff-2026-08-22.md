## 2. Read this before running the benchmark

### Trap A — v2 gained a degree, and naive scoring reads that as a regression

v2 now emits `unsupported` where it previously emitted `not_checkable` + null reason
`no_signal`. `unsupported` is in the `_ADVERSE` scoring bucket. So **with
byte-identical behaviour**, the relabelling alone moves cases:

| gold | v2 said `not_checkable` | v2 says `unsupported` |
|---|---|---|
| `supported` | miss | **false adverse** |
| `partially_supported` | miss | **false adverse** |
| `not_checkable` | **agree** | **false adverse** |
| `unsupported` | agree | agree |

A gold `not_checkable` case **loses an agreement and gains a false adverse** with
nothing about the decision changing. DEV-004 records 56 of 98 PILOT-001 claims coming
back `not_checkable`. That is more than enough to invert the headline and read as
"the fixes made it worse".

**The harness now scores every corpus twice:**

- **raw** — v2's four degrees against gold's five. What v2 actually emits now.
- **vocabulary-neutral** — `unsupported` folded back to `not_checkable`, i.e. exactly
  what the previous revision would have emitted for the same decision.

> Compare **vocabulary-neutral against the 64/98 and 3 false adverse** from the last
> run. That isolates the behaviour change.
> Compare **raw against vocabulary-neutral**. That isolates the relabelling.
> Neither number alone means anything.

### Trap B — the two engines are not asked the same question

v0.4.0's verdict is read from a sealed trace. v2's is recomputed live with
`declared_mode`, `source_boundary`, `claimed_material_is_a_named_gap`, `claim_scope`,
`passage_scope` and `passage_texts` that the v1 run never had. The first three are
corpus construction parameters, and on a constructed corpus a construction parameter
is close to the label — `relation="absent_from"` routes to coverage mode, and R1
returns `contradicted` off the named-gap flag alone.

Every printed block carries a **DECLARED-INPUT DISCLOSURE** counting how many cases
received each. Where those counts are high, the comparison is not like-for-like.

`--outputs-root` defaults to `<workbench>/../outputs`, which resolves to
`30_projects/claim-audit-lab/outputs` — correct for this layout. Override if needed.

**On `--trust-policy`.** Q1's fix is *inert* on PILOT-001 under the default, because
those traces carry no `trust_levels` at all. But `required` is not the fix either: with
no levels anywhere, it strips refutation from **every** passage including genuinely
primary ones, so it will suppress true contradictions along with false ones.

- `optional` → the floor. Shows the false-adverse problem as it stands.
- `required` → the ceiling. Shows what full provenance gating would buy.

The real answer needs trust levels reconstructed from source prefixes in the replay
harness — workbench work, not CAL work, and I could not write it without seeing the
trace format.

## 4. What to look at, in order

1. **Vocabulary-neutral agreement vs 64/98** — did four stacked fixes move behaviour?
2. **Vocabulary-neutral false adverse vs 3** — did Q1 + the mode fix recover those?
3. **Movement matrix**, specifically `not_checkable → contradicted`. That is the
   misclassified-coverage fix firing on claims like
   *"This packet does not establish requirements for a specific timeframe"*.
4. **Apparatus completeness block.** If most PILOT-001 cases show a guessed mode and
   no declared boundary, that is your ceiling — an input problem no decision layer can
   fix, and the strongest argument for the apparatus-contracts work.
5. **Raw vs vocabulary-neutral gap.** That is purely the new degree. If it is large,
   the scoring convention needs a decision before any figure gets published.

### The four behaviour changes

**Interval operator** — crashed with `ValueError` on `98 ± 2 °F` (affine conversion
applied to a tolerance, which is a width not a position). Produced false `supported`
when a passage carried an unrelated bound on the same dimension. Gave opposite answers
depending on whether you wrote `2.5 percent` or `25000 ppm`. All fixed; it now abstains
(`ambiguous`) when a side carries multiple bounds on the claim's dimension.

**Q4 is advisory** — it records its reading and removes no role. The multi-bound
abstention closes the demonstrated false-substantiation case but not the general one:
a passage with exactly one temperature bound that still isn't the claim's temperature
reads as unambiguous. Measured on 20 hand-written pairs, 2 still decide wrongly.
Binding a bound to its measurand is the open work.

**Resolution table reordered** — mode was *routing* rules, not parameterising
obligations. `_r_coverage_bounded` sat third and fires unconditionally for coverage
mode, so a claim the stage-0 lexicon guessed into coverage could not be decided by
evidence at all — a passage entailing at 0.989 lost to a substring match. New order:
caller-declared facts (R1, R2) → measured evidence (R3–R5) → reasoning about absence
(R6–R8). Refutation is now mode-blind (Popper: one counterexample falsifies a universal
negative); support stays mode-restricted (an excerpt can't establish global absence —
D11 intact).

**Q1 stopped failing open** — it read `trust is None` as "primary" and passed silently.
Now recorded as *not evaluated*, with `trust_policy` letting a caller say whether
absence should also withhold refutation.

## 6. Open decisions

**Deferred mode.** The lossiness principle says my fix didn't go far enough: mode is
still *decided* at stage 0, the point of minimum information. The fuller version carries
`modes: frozenset[Mode]` with both live unless declared, and lets stage 4 resolve it
with evidence in hand. Held pending this rerun.

**Scoring convention.** If the raw/folded gap is large, someone has to decide whether
`unsupported` belongs in the adverse bucket at all before any figure is published.

**Conditionals.** `any_of` is a small addition to the E2 table. Conditionals are not —
the antecedent is a scope restriction, not a conjunct, and truth-table aggregation gets
them wrong whenever the antecedent is false. Needs a decision before either side builds
to it.
