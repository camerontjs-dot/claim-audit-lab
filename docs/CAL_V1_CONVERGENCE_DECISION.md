# CAL V1 convergence decision

Status: **candidate scope freeze for maintained convergence**

Authority baseline: `claim-audit-lab` main `32275a239b68af383a56bca843e28cbc1e343976`.

This record freezes the bounded product claim and implementation scope before maintained CAL V1 candidate code is assembled. Research PRs remain evidence records and are not merged wholesale.

## Bounded V1 claim

Given an immutable admitted Contract B evidence world and an explicitly typed proposition in a supported semantic family, CAL may measure bounded semantic structure, independently ground/complete it when required, bind semantic authority to the exact semantic object and proposition, derive proposition-relative categorical relations, compose compatible relations without scalar decision thresholds, preserve uncertainty/provenance, and project an inspectable downstream epistemic result.

The candidate does not claim generic NLU/NLI, automatic decomposition/target extraction, source truthworthiness, perfect retrieval/completeness, operational authorization, or execution permission.

| direct event ordering | `ADOPT_IN_V1` / deciding | narrow direct narrator-level grammar only; exactly one supported event each side of one `before/after`; independent source completion before authority; no transitivity/coreference/general temporal QA |

| learned/NLI | `DIAGNOSTIC_ONLY` | may emit measurement diagnostics only; never terminal authority or majority-vote truth |
| undeclared/other family | `UNSUPPORTED_SEMANTIC_FAMILY` | fail closed; no legacy threshold/rules fallback |

## Root composition decision

Composite Contract A roots are **not composed in V1**. Child propositions may be independently audited; the root result is `NOT_COMPOSED` with preserved child identities. Root `all_of` semantics are useful but not essential to the bounded V1 claim, so the research stop rule favors exclusion over another semantic research lane.

## Architectural invariants

1. Measurement is not truth: `measurement != semantic warrant != proposition-relative relation != proposition conclusion`.
2. Audit context is immutable and binds the exact typed proposition, Contract B/bundle identity, admitted passage identities/hashes, lineage and aperture state supplied to CAL.
3. Each measurement records the full evidence world available and the exact consumed passages. Non-consumed admitted evidence remains recoverable.
4. Semantic authority binds the exact completed semantic object. Caller-stipulated semantic fields cannot manufacture authority where independent source completion is required.
5. Proposition binding is exact and content-addressed; same-ID changed propositions, direction reversals, substitutions and stale receipts fail closed.
6. Relation is proposition-relative. Evidence is not intrinsically `support` or `refute`.
7. Composition is categorical and scoreless. Mixed `SUPPORTS` + `REFUTES` resolves to abstention, never a winner.
8. All deciding relations in one composition must bind the same exact admitted evidence world. Cross-bundle/world composition fails closed.
9. Unsupported families and unresolved stages fail closed and never fall through to the historical v0.5 retrieve→entail→rules verdict path.
10. Historical v0.5 behavior remains reproducible during migration; the new candidate receives a separate operator/API surface before any default replacement.

## Contract B boundary

V1 consumes an immutable evidence-world view containing at minimum:

- exact typed proposition identity/content hash;
- Contract B version/profile and exact bundle identity/hash;
- admitted passages with source/passage identities and content hashes;
- aperture/completeness state provided upstream;
- root/child lineage when present.

Retrieval score, nomination role, source class and compatibility metadata do not become epistemic truth merely by appearing in Contract B.

Released Contract B 1.2 remains a valid current intake target. A successor may replace it only after its producer/consumer conformance is independently established; CAL must not invent B2 production authority during this convergence.

## Contract C boundary

Released Contract C 1.0 cannot faithfully carry exact unresolved/non-deciding causal evidence without semantic laundering. Research has qualified an in-band `non_deciding` candidate and separately shown a bound companion receipt can carry the data.

For CAL V1 the selected architectural target is an **in-band Contract C successor with `non_deciding` attribution**, because Contract C's published purpose is the immutable CAL-attributable result state required by legitimate downstream consumers. Requiring a mandatory sidecar would weaken that boundary. This decision does **not** assign an official successor version or authorize Contract C promotion. CAL candidate code may target the qualified research shape while promotion remains contract-governed.

## Legacy migration

The released v0.5 `audit` / `demo` surfaces remain historical/compatibility behavior during convergence. The maintained research-backed candidate is introduced separately. No unsupported V1 family may delegate to the old scalar/threshold rule engine for a deciding result.

## Qualification freeze rule

Maintained candidate source must be frozen before the fresh V1 qualification cohort is added/executed. Qualification may add fixtures/tests/receipts but must not mutate candidate source after gold/expected outcomes are exposed and still count as the same qualification. A failed or unsafe qualification is preserved as failure and requires a successor candidate.
