## Observed precursor

For a warranted temporal `UNRESOLVED` or `IRRELEVANT` relation, Contract C 1.0 cannot emit a normal evidence contribution without assigning `support` or `counterevidence`. The frozen bound projector therefore preserves terminal `not_checkable` through a typed `state:` basis and records omitted relation IDs only in its research-side projection receipt.

The precursor establishes compression, not yet downstream information insufficiency.

## Research question

Can an independent contract-level consumer, given only canonical valid Contract C 1.0 plus the exact bound Contract-B index, identify the exact admitted evidence reference that formed the unresolved temporal basis without importing CAL, the temporal projector, or producer-private state?

## Independent-consumer aperture

The consumer may use every normative Contract C field and the complete bound Contract-B index:

- exact Contract-B version/id/hash;
- proposition IDs/text hashes;
- all indexed evidence references;
- Contract C contribution IDs/channels/evidence refs;
- measurement basis references;
- conclusion terminal branch, causal form, basis members, residual IDs, and rule roles.

It must treat `state:` basis IDs as the released contract specifies: opaque typed CAL-attributable state identities. It may not reverse-engineer producer-private hashing conventions or re-run temporal semantics over source prose.

This is a causal-attribution reconstruction test, not a fresh semantic audit.

## Preregistered worlds

Use one exact negative-event temporal proposition and two admitted negative-event passages in a common immutable evidence world. Both passages are available to CAL and both are structurally capable of yielding the same bounded `UNRESOLVED` relation category.

Create two upstream executions over the same proposition and same admitted evidence world:

- World A: only passage A participates in the bound temporal proof projected to Contract C;
- World B: only passage B participates.

Both outputs must:

- bind the same Contract B version/id/hash within their paired world;
- report `completed / not_checkable`;
- report terminal branch `unresolved_categorical_relation`;
- contain no falsely polarized unresolved evidence contribution;
- pass exact released Contract C validation.

The causal ground truth is retained only by the evaluator for scoring and is not passed to the independent consumer.

## Positive control

A same-shape support world must project an ordinary `support` contribution. The independent consumer must recover the exact causal evidence reference through the contribution basis. Failure on this control invalidates the consumer apparatus.

## Falsifier for the gap hypothesis

The gap hypothesis is falsified if the independent consumer can uniquely identify the correct unresolved causal passage in both unresolved worlds from Contract C + bound Contract B alone, without non-contract semantic or producer-private knowledge.

## Support condition for the gap hypothesis

The gap hypothesis is supported with bounds if:

1. exact Contract C validation passes for both unresolved worlds;
2. the positive support control is uniquely reconstructable;
3. neither unresolved world exposes a normative evidence-reference path from the causal `state:` basis to the correct Contract-B passage;
4. the consumer therefore reports the unresolved causal evidence as underdetermined rather than guessing;
5. changing which passage actually participated changes producer-private/research proof state but does not create a normative Contract C evidence edge to that passage.

## What would still remain unknown

Even a positive gap result would not select a Contract C schema change. Competing fixes would still require a separate design experiment, including at least:

- neutral/non-deciding contribution channel;
- separate evidence-role attribution structure;
- another compact state-to-evidence binding representation;
- leaving Contract C unchanged and accepting that exact causal reconstruction requires a separate immutable producer receipt.

No fix is preregistered as preferred.
