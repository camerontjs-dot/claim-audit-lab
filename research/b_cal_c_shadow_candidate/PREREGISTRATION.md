## Frozen authority policy for this experiment

There is **no default authorization**.

The frozen Contract-B input does not itself carry a CAL semantic-warrant receipt for RC7F measurement proposals. Therefore:

- `CLAIMED` measurement proposal + no warrant receipt → `insufficient_authority`;
- instrument cue outside supported surface → `semantic_relation_unknown` / measurement unresolved;
- no relevant cue → operator not applicable;
- execution exception → execution failure;
- no combination of confidence, deterministic execution, instrument agreement, nomination lane, source trust, or legacy verdict grants authority.

The candidate may preserve a proposal while preventing it from strengthening its epistemic conclusion.

## Contract C projection rule

For a successfully executed proposition whose semantic measurements remain unwarranted:

- proposition execution remains `completed`;
- completion is `not_checkable`;
- `semantic_validity` is `{"state":"performed","value":"unknown"}`;
- other unexecuted generic stages remain `not_performed`;
- retained Contract-B contributions remain residual/non-deciding;
- no causal basis is invented;
- the reported verdict is `not_checkable`;
- detailed non-authoritative proposal structure stays internal because Contract C 1.0.0 has no structured slot for it.

Execution failure must remain distinct from epistemic `not_checkable`.

## Corpus plan

Primary boundary corpus: reconstruct the exact frozen real Contract-B handoff used by the Contract-C 1.0.0 release lock and run it end-to-end.

Controlled tests may exercise internal authority/projection state using real Contract-C proposition shapes, but they must not be represented as fabricated Contract-B observations. A requested distinction absent from the available valid Contract-B corpus is recorded as unavailable rather than synthesized upstream.

The run will inventory which requested semantic states are actually represented by the real B object and separately record coverage gaps.

## Primary acceptance conditions

### Boundary conformance

- exact valid Contract B intake succeeds;
- released CAL behavior and legacy Contract-C bytes remain reproducible;
- shadow Contract-C output validates under the exact frozen 1.0.0 validator and bound Contract-B index;
- canonical identity is deterministic.

### Authority safety

- no RC7F proposal is authorized without a warrant receipt;
- agreement cannot grant authority;
- source trust or nomination metadata cannot grant authority;
- unresolved proposal cannot strengthen a legacy or shadow conclusion.

### Epistemic preservation

Tests must distinguish, where exercised: operator not applicable, operator unresolved, insufficient authority, source-established semantic unknown if supplied by a future authority receipt, extraction unresolved, and execution failure.

### Projection honesty

Detailed proposal state may be omitted from Contract C only as internal non-authoritative measurement state. Any downstream-relevant loss must be recorded as a concrete projection-loss counterexample rather than repaired by mutating C.

## Differential classification

Every legacy/shadow divergence is classified as exactly one primary class:

- likely legacy compression;
- candidate improvement supported by evidence;
- candidate regression;
- unsupported candidate strengthening;
- Contract B information limitation;
- Contract C projection limitation;
- authority unresolved;
- evaluator/apparatus uncertainty.

## Falsifiers

The candidate fails authority safety if any of these occurs:

1. a measurement proposal without a warrant receipt changes `not_checkable` to a stronger conclusion;
2. two agreeing instruments produce authorization where one alone would not;
3. source trust or Contract-B nomination lane changes semantic authorization;
4. an unwarranted proposal appears in Contract C as a causal basis member;
5. execution failure is collapsed into completed `not_checkable`;
6. Contract C validation requires adding a field to the frozen contract;
7. the ordinary released CAL path is modified.

## Non-claims

This experiment does not establish semantic-warrant architecture, universal natural-language competence, safe assertion/scope recovery, Contract-B completeness, Contract-C successor need, Decision Engine policy correctness, or production readiness.

No production `src/` modification, Contract B/C change, release, merge, or promotion is authorized by a successful run.
