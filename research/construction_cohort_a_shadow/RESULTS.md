## 4. A4 semantic-operator authority

### OBSERVED

Across the 33 cases, frozen operator judgments were:

- `A4_negation_consistency / invalid`: 11
- `A4_negation_consistency / valid`: 3
- `A4_negation_consistency / unknown`: 4
- `direct_claim_identity / valid`: 7

All **7 legacy contradictions** became explicit abstentions.

Six direct contradiction cases first diverged at semantic validity because A4 marked the refutation contribution invalid. The seventh, CG-24, retained one invalid A4 judgment plus one unknown judgment and also abstained.

Examples include:

- CG-03: direct contradiction → A4 invalid → no valid contribution
- CG-04: direct contradiction → A4 invalid → no valid contribution
- CG-12a / CG-12b: numeric/time mismatch contradiction → A4 invalid → no valid contribution
- CG-19: universal categorical exception → A4 invalid → no valid contribution
- CG-21: named-missing-material adverse case → A4 invalid → no valid contribution
- CG-24: scope/numeric contradiction → A4 invalid + unknown → semantic-validity abstention

### HYPOTHESIS

The predecessor operator replay is treating the A4 structural-negation consistency probe as a generic validity adjudicator for refutation contributions beyond the semantic family for which it has defensible authority.

### RESULT

**SUPPORTED, now on a broader corpus.**

The e2e-08 finding was not isolated. The 33-case run shows a systematic pattern in which A4 invalidation suppresses direct refutation authority across multiple semantic families.

### UNKNOWN

This does not prove the legacy contradictions are all semantically correct. It proves only that the current explicit replay does not have sufficient typed semantic authority to validate or invalidate them using A4 alone.

## 6. CG-23b counterexample

### OBSERVED

CG-23b supplies:

- an in-scope passage supporting the Building 4 claim;
- a high-scoring contradictory distractor governing a different scope.

Legacy CAL returns `not_checkable` through `A5_conflicting_evidence` because both support and contradiction clear thresholds.

The explicit replay:

1. begins with mixed support/refutation;
2. marks the refutation contribution `invalid` through `A4_negation_consistency`;
3. retains direct support as `valid`;
4. collapses the valid state to `support_only`;
5. emits `supported`.

### INFERENCE

This is the most important falsifier in Cohort A. The explicit path strengthened an unresolved/conflicting state into a positive decision because one semantic operator could invalidate the adverse arm while no equivalently typed scope/authority assessment constrained the support arm.

The parallel artifact is valuable precisely because it makes this causal chain inspectable.

### UNKNOWN

The study does not establish the correct production verdict for all scope-conflict patterns. It establishes that the current explicit decision basis is not yet safe to treat as authoritative in this family.

## 8. What this run establishes

### OBSERVED

1. A clean 33-case blind execution surface can be regenerated from the canonical construction builder without exposing gold.
2. The frozen 25-case predecessor sentinel remains reproducible.
3. The parallel artifact executes over all 33 cases without execution failure.
4. It preserves useful raw/eligible/valid/aperture/operator distinctions.
5. The current explicit decision layer is substantially more conservative on adverse evidence and emits no contradiction on this corpus.
6. A4 over-application is a recurring operator-authority problem, not merely the e2e-08 curiosity.
7. Source-boundary semantics are not adequately represented in the explicit projection.
8. CG-23b demonstrates an unresolved/conflicting → supported strengthening that the prior polarity invariant did not catch.

### INFERENCE

The right next work is **not more random corpus scale** and **not threshold/model tuning**.

The smallest discriminating work is:

1. strengthen the research evaluator with a monotonicity invariant covering unknown/unresolved/conflicting → decided strengthening;
2. make operator applicability first-class and separate from validity;
3. run the already-motivated typed numeric/relational operator study;
4. add a bounded source-boundary/scope receipt experiment;
5. only then use SLG Cohort B for composition/quantifier coverage.

### UNKNOWN

Whether a corrected typed-operator layer will preserve enough adverse and boundary semantics to justify authoritative parallel decisions remains unproven.
