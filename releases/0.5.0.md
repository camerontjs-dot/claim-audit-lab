# Claim Audit Lab 0.5.0

CAL 0.5.0 adds the public deterministic exporter for immutable Apparatus Contract C 1.0.0.

This is a pre-1.0 MINOR release because the exporter is a new public capability. It does not change the CAL verdict policy or the frozen semantic implementation that the Contract C promotion evidence tested.

## Added

- `claim_audit_lab.contracts.contract_c` deterministic Contract C 1.0.0 exporter.
- Exact Contract-B version, bundle ID, and bundle hash binding.
- Exact CAL semantic implementation and canonical policy identity.
- Proposition and Contract-B evidence-reference binding.
- Retained support/counterevidence contribution state, including residual/non-deciding state.
- Aggregate measurement identity/value and exact co-maximal basis references.
- Explicit generic stage state and proposition/result-set execution state.
- Supported terminal-basis and causal-multiplicity forms without inventing a unique winner.
- Deterministic canonical JSON bytes and content-derived result-set identity.
- Fail-closed handling for unresolved Contract-B references, policy drift, unsupported rule families, and unpromoted multiplicity forms.

## Compatibility

Existing CAL audit semantics remain unchanged by this exporter release. The v1 retrieve→entail engine remains the ordinary `audit` / `demo` path; the falsified v0.2 lexical path remains selectable for preserved apparatus compatibility.

Contract C and CAL are independently versioned. CAL 0.5.0 is conformed to Contract C 1.0.0; neither version number implies the other.

No PyPI publication is part of this release. The GitHub Release carries the built wheel, source distribution, SHA-256 manifest, and machine-readable release-lock receipt.
